# JRSSB Empirical Style Profile

日期：2026-09-30。依据：20 篇 JRSSB 已刊论文（`corpus_manifest.csv`），正文截到 References 之前。分层遵循：OFFICIAL REQUIREMENT（官方硬性要求）、EMPIRICAL DOMINANT（多数样本一致）、EMPIRICAL COMMON（过半样本）、OPTIONAL（作者选择）。

## 1. 官方硬性要求（OFFICIAL REQUIREMENT）

- 摘要不超过 200 词；5--6 个关键词按字母序；摘要内不用引文与缩略语。
- 英式拼写。
- 定理按类型顺序编号；公式独立成行并按 (1),(2),... 编号；推导放附录，正文只留关键公式。
- 表格放正文末尾；无竖线；表身内无横线；数字右对齐。
- 图题与图例写在正文文件内；每幅图单独文件；多面板合并为一个文件；面板左上角标 A、B、C；图例正下方一行 `Alt text:`。
- 正文 12pt、双倍行距（每页 28 行）、A4；含全部内容低于 30 页；超过约 35 页招致负面评审。
- 补充材料每份不超过 2MB；正文必须引用；数据不放进补充材料。
- 数据可用性声明作为独立小节放在致谢之前；录用前代码须有 DOI 并在正文与参考文献中给出。
- 单盲评审；投稿系统 ScholarOne。

## 3. 结构共性与配套（EMPIRICAL COMMON / DOMINANT）

- 章节骨架（20/20）：Introduction → 问题设定或方法 → 理论 → 数值研究 → 真实数据 → Discussion。
- 引言三段式（DOMINANT）：普遍情境、按主题归组的文献、显式贡献句。摘要开场以情境句或本文动作为主。
- 编号假设/条件：16/20。
- 算法框：10/20。
- 定理解释段用编号 Remark：11/20。
- 定理带标题：8/20。
- 讨论里显式点名 limitation：9/20。
- `Proof of Theorem` 式证明小节：12/20。
- 专门记号段：7/20（OPTIONAL）。

## 6. 标题与命名（EMPIRICAL COMMON）

- 词数 5--15，中位 9--10。
- 冒号副标题：约三分之一使用，副标题陈述性质或保证。
- 词汇：`guarantees` 出现两次，`efficient / efficiency` 三次；`certified / certificate` 未出现。
- 数值节命名：Numerical Studies、Simulation Studies、Simulations、Experiments、Empirical studies。
- 应用节以数据域命名：Application to ... Studies、Example: ... Study、Application example: ...。
