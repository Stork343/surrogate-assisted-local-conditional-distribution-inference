JRSSB V5 complete LaTeX sources

Run bash build_all.sh with a LaTeX installation containing pdflatex and BibTeX.
The outputs are paper/manuscript.pdf, paper/supplement.pdf and submission/cover_letter.pdf.
On Windows, use the corresponding commands from the paper and submission directories.
The relative figure directory ../figures/ must be retained.
Supplied .bbl files reproduce the frozen bibliography; references.bib is unchanged.
No statistical program is run by this build script.
