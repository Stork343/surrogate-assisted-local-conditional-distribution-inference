## 核心方法

对同一个联合协方差模型 Q, 比较 Anchor 与候选权重的高斯临界值, 定义 g_Q(lambda)=c_Q(0)-c_Q(lambda). 在联合协方差置信集合内取这一成对差的下确界, 再最大化下界. 零权重的收益及其认证下界恒等于零.

固定非退化阈值网格上, 成对临界值差的扰动满足 `C * lambda * covariance_error`. 因此, oracle regret 保留了最优权重 lambda_star 的因子. 不需要 oracle 唯一, 也不要求借用目标函数为凸函数. 输出协方差的非退化条件与“修正路径是否趋于零”是不同条件.

二元子模型中, 关联信号 theta 的可检出尺度为局部参考数量的负二分之一次方, 相应的 oracle 临界值收益为负一次方尺度. 这是指定子模型和候选路径的结果, 不应改写成整个一般模型的统一极小极大定理.

## 数值与理论的适用范围

确定性高斯积分例子是总体机制验证, 不是新的模拟实验结论. 协方差置信球采用保守 Bernstein 常数; 单次接口测试不等于对名义置信水平的蒙特卡洛验证. Python 模块尚未实现一般多阈值鲁棒下确界的高效数值求解. 局部最优化给出的内层目标值不能当作已经认证的下界.

11 页技术稿中的平滑扰动定理适用于固定网格和具有统一正下界的输出协方差. 递增阈值网格、协方差近奇异、原有三路轮换的联合依赖控制、以及 EPA 周块实现仍须完成相应推导与计算. 独立评价样本下的覆盖转移已经写出; 其中的高斯近似误差需要按最终实现继续落实.
